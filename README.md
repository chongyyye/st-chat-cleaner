# 🧹 酒馆聊天记录瘦身净化器 (SillyTavern Chat Cleaner)

专为解决酒馆（SillyTavern）长时间聊天导致聊天文件（`.jsonl`）异常暴涨（几十兆到上百兆）、加载卡顿或内存溢出而设计。


---

## ✨ 核心特性

1. **🌿 另存为新分支（绝对安全防翻车）**
   - 不会修改或破坏您现有的原聊天记录；
   - 自动生成全新净化版聊天分支并无缝切换，老聊天原封不动保留供对照。
2. **📝 完整保留作者注释 (Author's Note)**
   - 彻底修复旧版清理工具“清空作者注释”的痛点；
   - 自动识别并完整保留作者注释文本、插入深度（Depth）、插入频率（Freq）与角色设置。
3. **⚡ 酒馆内一键生效**
   - 再也不需要“导出 -> 打开网页 -> 上传 -> 下载 -> 替换”的繁琐流程；
   - 在酒馆扩展面板里点击按钮，直接就地完成瘦身与保存。
4. **🔬 实时体积健康诊断**
   - 实时显示当前聊天的层数、预估总大小、有效文本占比与可释放垃圾数据。
5. **🎛️ 细粒度清洗选项**
   - [x] 保留作者注释 (Author's Note)（默认开启）
   - [x] 清理未选中的历史 Swipes（仅保留当前楼层选中的内容，默认开启）
   - [x] 清理首行世界书/变量快照缓存 (LWB_SNAP / Variables)（默认开启）
   - [x] 清理楼层隐藏元数据与巨型向量 (Metadata)（默认开启）
   - [x] 清理第三方扩展附加属性 (Extra)（默认开启）

---

## 🚀 安装步骤

只需把 `st-chat-cleaner` 文件夹放入您的酒馆第三方插件目录即可：

1. 打开您的 SillyTavern 根目录；
2. 进入目录：
   ```text
   public/scripts/extensions/third-party/
   ```
3. 把 `st-chat-cleaner` 整个文件夹复制进该目录下；
4. 刷新或重启酒馆网页；
5. 点击酒馆右上角的 **插件图标 (扩展 Extensions)**，在列表中就能看到 **【聊天记录瘦身净化器】**！
